# Titan Flagship Command & Subsystems Specification

## 1. Flagship Archetypes
- **O'Neill-Class Titan (Asgard)**: Advanced Ion Arrays, Hyper-Shielding.
- **Anubis Dreadnought (Goa'uld)**: Heavy Plasma Lance, Sarcophagus Core.
- **Nanite Hive Ship (Replicator)**: Self-repair carapace, Drone Swarms.
- **BC-304 Battlecruiser (Tau'ri)**: Railgun Batteries, Asgard Beam Weapons.
- **Phased Super-Dreadnought (Tollan)**: Phase Shift Generator, Ion Cannons.
